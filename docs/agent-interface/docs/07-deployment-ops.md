# 07 · 单机部署、运维与恢复（N5095 / 4GB / 512GB）

## 已知条件

历史设计输入为 Ubuntu 24.04、Intel N5095、4GB 内存与 512GB SSD，本次未实测。旧考试部署是静态官网、云端 edge、lab authoritative 混合链路，**不是成员产品已部署的拓扑**；不继承考试 `/recruitment`、回源/暂存、账号或 DB。

内部成员与招新筛选是独立产品。先同仓 `member-platform/` 独立运行与 PR 审查；下文仅是后续成员运维方案，不是生产执行记录。Gitea/连接器/官网模型未交付，域名/反代、RPO/RTO、服务账号和真实数据迁移另审。

## 本地入口与未来拓扑

```text
本地成员 http://localhost:8902
    ├── /org      -> 成员网页（包括可信确认/审核）
    └── /api/v1   -> 成员 API
                         │
                  独立成员 DB / 账号 / 会话

本地考试 http://127.0.0.1:8901 -> 根 server / 独立考试 DB
```

生产由获授权负责人另定独立服务/网络入口与 TLS；不以本页示例确定公网域名、`/internal` 或 `/recruitment` 路由。内置模型如后续启用只调用远端 API，不在本机推理。

- 只暴露必要 HTTPS 端口；Gitea SSH 另审，DB 默认不开放公网。
- 如使用 Compose，独立成员持久卷/配置/秘密、日志轮转/healthcheck/资源预算；systemd 独立服务同样可行。不能复用考试部署脚本或指向考试 DB。
- 沿用 FastAPI/SQLite 技术不等于继承官网/考试认证和数据库；不重写或搬迁官网。

## 资源预算原则

4 GB 内存是**硬性约束**，不是给 Gitea、API、DB、Redis、向量服务各分 1GB 的理由。部署前执行：

```bash
free -h
swapon --show
lsblk -f
df -h
docker stats --no-stream 2>/dev/null || true
systemctl --type=service --state=running
```

记录官网现有真实 RSS/峰值、IO、CPU 与磁盘使用率，再确定剩余预算。**Gitea 运行、备份、反代与数据库的峰值需要通过压测测量**，不能仅凭 CPU 型号判断能承载多少人。

### 倾向不做

- 本地大模型推理、大型向量数据库、多个重型 CI runner、本机密集模型训练、复杂任务队列、Prometheus + Grafana + 多监控后端全套。
- 公开网络可见的无认证 LLM 聊天接口。

## 建议运维最低集

- TLS 证书有效期监控；反代与 API 健康检查。
- CPU、RSS、剩余磁盘、SSD SMART、OOM、API 5xx、认证失败率、镜像同步失败告警。
- API 请求超时、每用户/每客户端速率限制，第三方 GitHub/Gitea 调用频率限制。
- Docker 日志限制或 journald 保留上限；不得记录 Bearer Token 或整个表单敏感内容。
- 数据库备份 + Git 仓库备份 + Gitea 配置/附件备份 + 系统配置与密钥恢复说明；备份**离机保留**。

## 备份与恢复

1. 制定明确 RPO（可接受数据丢失时间）和 RTO（恢复时间）。初始建议作为讨论起点：RPO ≤ 24 小时；RTO ≤ 24–48 小时，但不能在未演练前声称满足。
2. 自动化每日备份并设置轮换；至少一份离机/异地。
3. 备份加密，备份凭据与生产凭据分离；不要把密钥直接备份在公共仓。
4. 每季度在隔离环境做一次**实际恢复演练**，同时验证数据库、仓库和登录链路；保留记录。
5. 512GB SSD 预留足够空闲空间用于 Git 增长、备份临时文件、系统更新；针对附件/大模型权重设置配额，严禁把主机当训练数据海量仓库。

## 典型失效和降级

| 故障 | 面向成员的表现 | 恢复优先级 |
|---|---|---|
| DeepSeek API 异常 | 官网可选聊天不可用；CLI/网页仍可办理 | 低于业务 API |
| GitHub 网络故障 | 显示缓存 + 最后同步时间；不伪称实时 | 中 |
| Gitea 进程失败 | 内部 Git 暂停；业务申请尽量不受影响 | 高 |
| 认证服务异常 | 新登录不可用；无有效凭据时拒绝访问 | 高 |
| 业务 DB 不可用 | 申请与状态查询不可用；避免本地假成功 | 最高 |
| 主机不可用 | 网站与内部服务离线；执行离机恢复预案 | 最高 |

## 可选内置模型预算

如将来保留官网 DeepSeek Flash 对话：只对认证成员开放；每人配置限额并记录服务器计量的实际 API 开销。历史讨论的 **2 元/人** 只能视为预算量级参考，需由成员数、周期、实际模型价格、上下文长度重新测算；若额度耗尽提示切换 CLI 或自有 Agent，不应该中断基础事务。
