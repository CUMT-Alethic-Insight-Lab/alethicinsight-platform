# 成员 API 契约：兼容导航

本目录原 `openapi-skeleton.yaml` 已从考试仓移除，避免重复维护成员契约。请从独立[成员仓 README](https://github.com/CUMT-Alethic-Insight-Lab/alethicinsight-member-platform#readme)进入当前 API 文档与契约，并按成员运行时 OpenAPI 验证；不把本目录当作考试 API 定义。
